# IPL Cricket Data Analytics (2008–2026)

## Project Overview
An end-to-end cricket data analytics project focused on analysing Indian Premier League (IPL) match data from 2008 to 2026.

The goal is to explore team performance, player statistics, match trends, toss impact, and other important insights using data analytics tools.

## Tools & Technologies
- Microsoft Excel 2021
- Oracle SQL
- Python
- NumPy
- Pandas
- Power BI

## Project Structure
- `Dataset/` – Raw and cleaned IPL datasets
- `Excel/` – Data exploration, cleaning, and analysis
- `SQL/` – SQL queries and analysis
- `Python/` – Data analysis using Python
- `PowerBI/` – Interactive dashboards
- `Reports/` – Final reports and insights
